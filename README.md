# ADR LC Training Cache Dashboard

Versi terpisah untuk Vercel dari dashboard training berbasis cache lima sumber.

Mulai dari **VERCEL_SETUP.md**. Petunjuk backend ada di **MULAI_DI_SINI.md**.

- Dashboard, Laporan Meetdir, controller Database
- Filter periode/sumber/jenis/kategori/divisi; ekspor PDF
- Login dashboard; token Apps Script hanya pada server
- Data simulasi hanya dengan `?demo=1`

`npm install` ? `npm run dev` ? `npm test` ? `npm run build:vercel`

Tidak ada file karyawan, token, atau spreadsheet sumber di repository.
